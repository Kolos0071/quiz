# Хэллоуинский квиз

Квиз для ведущего в одном файле: откройте `halloween-quiz.html` в браузере (двойной щелчок).
Картинки лежат в `img/`, музыка — в `audio/`; держите эти папки рядом с HTML.

Управление: → / ← — слайды, Пробел — таймер, Enter — ответ, P — звук, M — меню, S — счёт, F — полный экран.
Вопросы и ответы редактируются в объекте `QUIZ` в начале скрипта.
